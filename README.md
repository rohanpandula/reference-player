# Reference Player

A noncommercial media player for Apple TV, iPhone, iPad and Mac, focused on preserving the picture
and sound in your media. Connect your own Plex, Jellyfin, Emby or IPTV sources.

See the [build instructions, features and validation limits](.github/README.md).
Report issues and request features in [this repository](https://github.com/rohanpandula/reference-player/issues).

Reference Player is a fork of [Rivulet](https://github.com/l984-451/Rivulet) by Bain Gurley.
